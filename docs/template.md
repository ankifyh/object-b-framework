# 情绪拆解模板

[![中文](https://img.shields.io/badge/lang-中文-red.svg)](template.md)
[![English](https://img.shields.io/badge/lang-English-blue.svg)](template.en.md)

> 每次情绪升起，用这个模板拆解。不用分析，不用深挖，写下来就已经破了一半。

---

## 基础版（30秒）

```
📌 当前情绪：_______

🔍 触发事件（用一句话说发生了什么）：
真实事件 ☐ / 想象事件 ☐

🎯 我内心预测了什么：
「我预测_____________________」

✅ 验证结果：
如愿以偿 ☐  预期落空 ☐  意外惊喜 ☐  意料之中 ☐  平静状态 ☐
```

---

## 进阶版（3分钟）

```
📌 当前情绪：_______
   —— 身体感受：_______
   —— 想要做什么：_______

🔍 触发事件：
   发生了什么？_______
   这是真实发生的，还是我脑补的？_______

🎯 我的预期：
   「我预测______会发生」
   这个预期从哪来的？（过去的经历？别人的影响？）_______

✅ 验证结果：
   预期被验证了，还是落空了？_______

💡 破局：
   我能控制的一件极小的事是什么？_______
   如果换个预期，会有什么不同？_______
```

---

## 使用建议

- **情绪刚上来的时候用** —— 不要等冷静了再用，越早越好
- **如实写，不要美化** —— 这个模板只有你自己看到
- **坚持下去** —— 用 7 天，你会越来越了解自己的预期模式
