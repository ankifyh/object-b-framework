# 如何停止精神内耗？

> 一个模型帮你彻底理解内耗的本质，然后停止它。

---

我花了很多年才想明白一件事：**内耗不是因为你想太多，而是因为你困在同一个「预期」里出不来。**

先忘记那些教你「别想太多」的建议——如果大脑能控制，没人会选择内耗。

内耗的本质，用预期验证模型来解释，非常清晰：

## 内耗 = 反复验证同一个失败的预期

你有一个预期，但这个预期被现实违抗了。你的大脑不接受这个结果，于是反复回放：「如果当时我那样做就好了」「如果他理解我就好了」。

大脑这么做，是想找到一个「修正方案」来让预期成立。但问题是——**已经发生的事，不可能修正。**

所以内耗是一个死循环。

## 停止内耗的 3 个步骤

### 第一步：找到那个预期

问自己：「我到底在期待什么？」

- 你在期待对方道歉？但他不会。
- 你在期待事情重来一遍？但不可能。
- 你在期待自己当时做得更好？但已经过去了。

把那个预期**写出来**。不写出来，大脑会一直转；写出来，它就变成一个物体，你可以审视它。

### 第二步：承认预期已失败

这是最难的一步。

对着你写出来的预期，对自己说三遍：
「**这个预期失败了。**」

不是「不应该失败」，不是「对方不该这样」——就是「这个预期失败了」。

痛苦不是因为事情发生了，而是因为你还在期待事情没有发生。**当你承认预期失败的那一刻，内耗就断掉了。** 不是停止了，而是断掉了。

### 第三步：建立新预期

旧预期死了，你需要一个新预期。否则情绪回落到焦虑。

新预期应该是**可控的、现实的**。

- ❌「我希望他从没说过那句话」（不可控）
- ✅「我预期自己会在接下来一周内消化这件事，每次反刍时做三次深呼吸」（可控）

控制预期 = 控制情绪。

## 关于预期验证模型

> **情绪 = 预期 × 验证结果**
