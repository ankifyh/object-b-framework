# 总是很焦虑怎么办？

> 焦虑不是你的敌人——它是你的预期清单太长，而你的大脑担心它完不成。

---

焦虑这件事，我太熟悉了。

那种明明什么都没发生，却坐立不安的感觉；那种脑子里同时有十几个声音在说话的感觉；那种明明在休息，身体却像在备战的感觉。

市面上教你「深呼吸」「冥想」「转移注意力」的方法很多。它们有用，但治标不治本。

我今天想从源头拆解焦虑。用**预期验证模型**。

## 焦虑的本质：不确定的预期太多

先看核心公式：

> **情绪 = 预期 × 验证结果**

愉悦 = 预期被验证；痛苦 = 预期被违抗。

那么焦虑是什么？**焦虑 = 预期不确定**。

你有一个或多个预期，但这些预期还没被验证，而且你可能无法控制验证结果。你的大脑同时模拟好几种可能性——每一种都是一个不同的预期——然后在这些预期之间来回跳转，停不下来。

- 你焦虑一场面试 → 你有预期（被录取/被拒绝），但结果不确定
- 你焦虑一段关系 → 你有预期（对方喜欢你/不喜欢你），但结果不确定
- 你焦虑健康 → 你有预期（会好/不会好），但结果不确定

**焦虑不是负面情绪，它是一种「待验证态」**。就像电脑上的「运行中」状态，它很消耗资源。

## 焦虑的解法：把「不确定预期」变成「确定预期」

你需要的不是消灭焦虑，而是**关闭那些待验证的预期**。

### 第一步：清单化你的焦虑

焦虑之所以让人难受，很大一部分原因是它模糊不清。你说「我焦虑」，但你不知道具体在焦虑什么。

拿出一张纸，把你焦虑的所有事情写下来：

1. 我焦虑下周的汇报（预期：做得好/不好）
2. 我焦虑她不回我消息（预期：她不喜欢我了）
3. 我焦虑自己的职业发展（预期：我会被淘汰）

写下来，焦虑就减少一半。因为大脑不用再同时记住所有事情了。

### 第二步：对每个预期问 3 个问题

**① 这个预期是我能控制的吗？**

如果不能控制，它就不值得焦虑。比如「她会不会回我消息」——你能控制她的行为吗？不能。所以关掉这个预期。

把预期从「她应该回我」改成「我发了消息，无论回不回我都接受」。

**② 最坏的结果我能承受吗？**

大多数时候，答案是「能」。最坏被拒绝、最坏没通过、最坏失去联系。你不会死。

当你知道最坏结果你能承受，焦虑就变成了准备状态——「如果最坏的结果我能承受，那我还有什么好怕的？」

**③ 我现在能做的一小步是什么？**

焦虑的秘密：**行动是最好的预期稳定器。**

当你采取行动，不确定预期就变成了可验证预期。
- 焦虑汇报？现在写前 3 页 PPT。
- 焦虑关系？发一条消息，验证你的预期。
- 焦虑未来？列出今天能做到的 3 件事。

**总结：焦虑不是你不好，是你的大脑同时挂着太多「待验证」的预期。列出它们，检查可控性，采取行动——焦虑就会从模糊的压迫感变成具体的、可解决的问题。**
