# Emotion Breakdown Template

[![中文](https://img.shields.io/badge/lang-中文-red.svg)](template.md)
[![English](https://img.shields.io/badge/lang-English-blue.svg)](template.en.md)

> Every time an emotion arises, use this template to break it down. No analysis needed. No digging. Writing it down already breaks half the spell.

---

## Quick Version (30 seconds)

```
📌 Current emotion: _______

🔍 Trigger (describe what happened in one sentence):
Real event ☐ / Imagined event ☐

🎯 What I predicted:
「I predicted _____________________」

✅ Validation result:
Fulfilled ☐  Failed ☐  Surprise ☐  Expected ☐  Neutral ☐
```

---

## Deep Version (3 minutes)

```
📌 Current emotion: _______
   — Physical sensation: _______
   — What I feel like doing: _______

🔍 Trigger:
   What happened? _______
   Real event or something I imagined? _______

🎯 My expectation:
   「I predicted ______ would happen」
   Where does this expectation come from? (Past experience? Others' influence?) _______

✅ Validation result:
   Was my expectation validated or failed? _______

💡 Breakthrough:
   What's one tiny thing I can control right now? _______
   How would things look if I held a different expectation? _______
```

---

## Tips

- **Use it when the emotion is fresh** — don't wait until you've calmed down
- **Be honest, don't sugarcoat** — only you see this template
- **Stick with it for 7 days** — you'll start recognizing your own expectation patterns
