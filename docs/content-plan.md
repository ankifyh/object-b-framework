# 7天内容脚本 — 预期验证模型·种草系列

> 格式：小红书/即刻/知乎，每篇 200-300 字，配简单排版。
> 目标：用场景切入，不讲理论，只展示"这个东西有用"。

---

## 第1天：焦虑

**标题：你焦虑是因为你在预测**

你有没有发现，焦虑的时候你脑子里一直在想一件事——「万一搞砸了怎么办？」

你还没搞砸呢。但你已经提前"看到"了搞砸的画面。

这就是预期验证模型说的：**情绪不是来自现实，来自你内心的预测。**

你的杏仁核在喊"危险！"，但危险根本没发生。

试试这个：
1. 把你预测的那个结果写出来——「我预测____会发生」
2. 问自己：这是真实发生的事，还是我自己脑补的？
3. 找到一件你能控制的极小的事，做它

写了告诉我，你发现了什么。

#情绪管理 #焦虑 #认知科学 #自我觉察

## 第2天：愤怒

**标题：你不是在生气，你是失控了**

你被放鸽子了。第一反应：气炸了。

但仔细想：让你生气的真的是"对方临时取消"这件事吗？

不是。让你生气的是你心里的一个预期——「ta应该守信」。

这个预期没有被验证，你失控了。

**愤怒的本质不是对方做错了什么，是你的预期没有得到验证。**

对方只是触发了这个预期，但这个预期是你的。

试试下次生气时问自己：
- 我的哪个预期没被满足？
- 这个预期合理吗？
- 现在我能做什么？

#情绪管理 #愤怒 #人际交往 #认知工具

## 第3天：拖延

**标题：你不是懒，你是在逃避微小失败**

想写一篇文章，打开文档——卡住了。
想做个方案，打开电脑——刷手机去了。

你以为拖延是因为"懒"。其实不是。

拖延的结构是这样的：
- 你想做好这件事（积极预期）
- 但每一步都在偏离预期（找不到文件、写不出第一句、排版不好看）
- 持续的微小"预期落空" → 负面情绪 → 逃避 → 拖延

**拖延不是懒，是积极预期被持续打击后的保护机制。**

破解方法：
1. 降低门槛到「写一行字就行」
2. 主动制造一个小成功
3. 完成≠完美

#拖延症 #效率 #自我管理 #认知科学

## 第4天：内耗

**标题：你在脑子里打了一场永远不会赢的仗**

选A还是选B？

选了A就想"万一选B更好呢"，选了B又想"早知道选A了"。

你以为是选择困难，其实是两个预期在打架：
- 预期A：「选A更稳妥」
- 预期B：「选B更有前景」

**未来的结果都没发生——你所有的纠结都是自己跟自己的想象在打架。**

破局：
1. 看清两个预期都只是预测，不是事实
2. 没有"正确"的选择，只有选了之后让选择变正确
3. 选了就不再回头看

#内耗 #选择困难 #决策 #认知心理学

## 第5天：想太多

**标题：你不是在思考，你是在反刍**

半夜两点，你在想白天说的那句话——"ta是不是生气了？""我当时应该这样说才对""完了ta肯定觉得我……"

停一下。看看你在做什么：

你脑子里有一个预期（「我应该表现更好」），然后用想象不断"验证"自己搞砸了。

**这不是思考，这是反刍。跟牛嚼草一样，把同一个念头反复嚼。**

你编了一个故事，然后信以为真。

试试：
- 问自己：我有什么证据证明ta生气了？
- 没有证据的话，这就是一个想象事件
- 依赖事实比依赖想象可靠

#想太多 #反刍 #焦虑 #情绪管理 #思维陷阱

## 第6天：人际关系

**标题：别人的愤怒不是冲你来的**

朋友发火、同事黑脸、网上有人跟你抬杠。

你的第一反应：我做错了什么？

其实对方的愤怒大概率跟你无关。

**每个人都在用自己内心的一套预期衡量世界。当现实偏离ta的预期，ta就失控了。**

那个跟你抬杠的人，不是针对你——是ta的"所有人都应该认同我"的预期没被满足。

那个黑脸的同事，不是讨厌你——是ta的"项目应该顺利推进"的预期落空了。

看清这一点，你就不会被别人的情绪带走。

#人际关系 #沟通 #情绪管理 #心理认知

## 第7天：总结

**标题：一个公式，看懂你所有的情绪**

这周我分享了一个模型，用一句话概括：

**情绪 = 预期 vs 现实的差异。**

你焦虑，是因为你在预测坏事要发生。
你愤怒，是因为你预期的事没发生。
你惊喜，是因为你以为要糟结果挺好。
你拖延，是因为每一步都在偏离预期。

没有复杂的术语。就四个步骤：

```
1. 我现在是什么情绪？
2. 触发这件事是真实的还是我想象的？
3. 我内心预测了什么？
4. 这个预测被验证了吗？
```

把它存下来。下次情绪上来的时候用一次。

你会发现自己没那么容易被情绪裹挟了。
