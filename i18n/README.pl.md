> **Emocja = Oczekiwanie vs. Rzeczywistość**

Czy miewasz takie momenty?

> "Wiem, że nie powinienem się martwić, ale nie mogę przestać."
> "Wiem, że powinienem zacząć, ale ciągle odkładam."
> "To wydarzyło się dawno temu, ale wciąż jestem zły."

**Twoje emocje nie pochodzą z zewnętrznych zdarzeń. Pochodzą z automatycznej prognozy twojego umysłu, która zderza się z rzeczywistością.**

To nie jest powierzchowne samopomocowe gadanie. To praktyczne narzędzie poznawcze, którego możesz używać każdego dnia.

---

## Szybka Diagnoza

### Kiedy się martwisz

```
Twój umysł przewiduje: "Mogę to schrzanić."
Ta prognoza wywołuje niepokój — nie dlatego, że się wydarzyła,
ale ponieważ już "zobaczyłeś" zły wynik w swojej głowie.
```

### Kiedy jesteś zły

```
Twoje oczekiwanie: "Powinni być uczciwi / godni zaufania / wyrozumiali."
Rzeczywistość odbiega od twojego oczekiwania i tracisz kontrolę.
Złość nie dotyczy tego, co zrobiła druga osoba — dotyczy twojego niespełnionego oczekiwania.
```

### Kiedy prokrastynujesz

```
Chcesz coś skończyć (pozytywne oczekiwanie).
Ale każdy krok odbiega od oczekiwania (wolno, plików nie znaleziono, blokada).
Ciągłe małe "porażki oczekiwań" → negatywna emocja → unikanie → prokrastynacja.
```

## Czym jest ten model

Jednym zdaniem: **Emocja = różnica między tym, czego oczekiwałeś, a tym, co się wydarzyło.**

| Pojęcie | Proste Wyjaśnienie |
|---------|-------------------|
| **Oczekiwanie** | Automatyczna prognoza twojego umysłu o tym, co wydarzy się dalej |
| **Wyzwalacz** | Coś realnego, co się dzieje, lub coś, co sobie wyobrażasz |
| **Emocja** | Reakcja twojego ciała po "zweryfikowaniu" oczekiwania |

**Kluczowe rozróżnienie:** Czy twój wyzwalacz jest realny, czy tylko sobie go wyobraziłeś?

### 4 Scenariusze

| Oczekiwałeś | Się Stało | Jak Się Czujesz |
|-------------|-----------|-----------------|
| Dobrze 👍 | Dobrze 👍 | Szczęśliwy, zadowolony |
| Dobrze 👍 | Źle 👎 | Zły, rozczarowany |
| Źle 👎 | Dobrze 👍 | Zaskoczony, odetchnięty |
| Źle 👎 | Źle 👎 | Przestraszony, przygnębiony |
| Neutralne | Cokolwiek | Spokojny |

## Jak używać

### Za każdym razem, gdy poczujesz emocję, wykonaj to ćwiczenie:

```
1. Co czuję? _______
2. Co to wywołało? (Realne czy wyobrażone?) _______
3. Co przewidziałem? "Przewidziałem, że _______ się wydarzy"
4. Czy moja prognoza się potwierdziła?  Spełniona / Niespełniona / Niespodzianka / Oczekiwana
```

Nie trzeba analizować. Nie trzeba kopać głęboko. Samo zapisanie już łamie połowę zaklęcia.

### Trzy Techniki do Natychmiastowego Użycia

**Gdy się martwisz:** Zapisz wynik, którego się boisz. Zapytaj siebie: czy to fakt, czy tylko twoja wyobraźnia?

**Gdy jesteś zły:** Zanim zareagujesz, zapytaj siebie: które moje oczekiwanie nie zostało spełnione? Czy było rozsądne?

**Gdy prokrastynujesz:** Obniż poprzeczkę do "napisz tylko jedno zdanie" lub "otwórz tylko plik". Stwórz małe zwycięstwo, by przerwać negatywną pętlę.

| **Główne pragnienia** | To, czego naprawdę chcesz pod powierzchnią oczekiwania |

| **Odciski przeszłości** | Jak przeszłe doświadczenia ukształtowały twoje obecne wzorce oczekiwań |
| **Śledzenie emocji** | Prześledź każdą emocję do jej podstawowego oczekiwania — im więcej ćwiczysz, tym ostrzejszy się stajesz |
