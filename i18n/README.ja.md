> **感情 = 期待 vs 現実のギャップ**

こんな経験はありませんか？

> 「不安だとわかっているけど、止められない。」
> 「やるべきことはわかっているけど、先延ばしにしてしまう。」
> 「あのことはもう過ぎたのに、まだ怒っている。」

**あなたの感情は外部の出来事から来ていません。あなたの心の中にある自動的な予測が現実と衝突することで生まれます。**

これは自己啓発の話ではありません。毎日使える実践的な認知ツールです。

---

## クイック診断

### 不安なとき

```
あなたの心の予測：「うまくいかないかもしれない」
この予測が不安を生みます — 実際に起きたからではなく、
頭の中で悪い結果を「見て」しまっているからです。
```

### 怒っているとき

```
あなたの期待：「相手は公平/信頼できる/理解があるべきだ」
現実がその期待からずれると、感情が暴走します。
怒りは相手の行動ではなく — あなたの満たされなかった期待から来ています。
```

### 先延ばししているとき

```
何かを終わらせたい（ポジティブな期待）。
でも一歩ごとに期待が裏切られる（遅い、ファイルが見つからない、書けない）。
小さな「期待の失敗」が積み重なる → ネガティブ感情 → 回避 → 先延ばし。
```

---

## このモデルについて

一言で言えば：**感情 = 期待していたことと実際に起きたことの差**

| 概念 | わかりやすく言うと |
|------|-------------------|
| **期待** | あなたの心が次に何が起こるか自動的に予測すること |
| **トリガー** | 実際に起きたこと、またはあなたが想像したこと |
| **感情** | 期待が「検証」された後の身体の反応 |

**重要な区別：** トリガーは現実のものですか？それともあなたが想像したものですか？

### 4つのシナリオ

| 期待 | 現実 | 感情 |
|------|------|------|
| 良い 👍 | 良い 👍 | 幸せ、満足 |
| 良い 👍 | 悪い 👎 | 怒り、失望 |
| 悪い 👎 | 良い 👍 | 驚き、安心 |
| 悪い 👎 | 悪い 👎 | 恐怖、落ち込み |
| 中立 | 何でも | 落ち着き |

## 使い方

### 感情を感じたら、このエクササイズを行ってください：

```
1. 今感じている感情：_______
2. トリガーは？（現実の出来事？想像？）_______
3. 何を予測していた？「_______が起こると予測していた」
4. その予測は検証された？ 達成 / 失敗 / 驚き / 想定内
```

分析は不要です。掘り下げる必要もありません。書き出すだけで半分は解決します。

### 今すぐ使える3つのテクニック

**不安なとき：** 怖がっている結果を書き出してください。それは事実ですか、それとも想像ですか？

**怒っているとき：** 反応する前に自問してください：私のどの期待が満たされなかったのか？それは合理的だったか？

**先延ばししているとき：** ハードルを「一文だけ書く」「ファイルを開くだけ」に下げてください。小さな成功でネガティブなループを断ち切ります。
