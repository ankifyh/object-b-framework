> **Tunne = Odotus vs. Todellisuus**

Onko sinulla ollut tällaisia hetkiä?

> "Tiedän, etten saisi olla ahdistunut, mutta en voi sille mitään."
> "Tiedän, että pitäisi aloittaa, mutta lykkään vain."
> "Tuo asia tapahtui jo kauan sitten, mutta olen yhä vihainen."

**Tunteesi eivät tule ulkoisista tapahtumista. Ne syntyvät, kun mielesi automaattinen ennuste törmää todellisuuteen.**

Tämä ei ole itsensä kehittämisen höpinää. Se on käytännöllinen kognitiivinen työkalu, jota voit käyttää joka päivä.

---

## Pikadiagnoosi

### Kun olet ahdistunut

```
Mielesi ennustaa: "Saatan epäonnistua tässä."
Tämä ennuste tekee sinut ahdistuneeksi — ei siksi, että se tapahtui,
vaan koska olet jo "nähnyt" huonon lopputuloksen päässäsi.
```

### Kun olet vihainen

```
Odotuksesi: "Heidän pitäisi olla reiluja / luotettavia / ymmärtäväisiä."
Todellisuus poikkeaa odotuksestasi, ja menetät hallinnan.
Viha ei johdu siitä, mitä toinen henkilö teki — se johtuu täyttymättömästä odotuksestasi.
```

### Kun viivyttelet

```
Haluat saada jotain valmiiksi (positiivinen odotus).
Mutta jokainen askel poikkeaa odotuksestasi (hidas, tiedostoja ei löydy, kirjoitusjumitus).
Jatkuvat pienet "odotusten epäonnistumiset" → negatiivinen tunne → välttely → viivyttely.
```

## Mikä tämä malli on

Yhdellä lauseella: **Tunne = ero sen välillä, mitä odotit ja mitä tapahtui.**

| Käsite | Yksinkertaisesti |
|--------|-----------------|
| **Odotus** | Mielesi automaattinen ennuste siitä, mitä tapahtuu seuraavaksi |
| **Laukaisin** | Jokin todellinen tapahtuma tai asia, jonka kuvittelet |
| **Tunne** | Kehosi reaktio sen jälkeen, kun odotuksesi on "tarkistettu" |

**Keskeinen ero:** Onko laukaisin todellinen vai vain kuvittelemasi?

### 4 skenaariota

| Odotit | Tapahtui | Miltä sinusta tuntuu |
|--------|----------|---------------------|
| Hyvä 👍 | Hyvä 👍 | Onnellinen, tyytyväinen |
| Hyvä 👍 | Huono 👎 | Vihainen, pettynyt |
| Huono 👎 | Hyvä 👍 | Yllättynyt, helpottunut |
| Huono 👎 | Huono 👎 | Pelästynyt, masentunut |
| Neutraali | Mitä vain | Rauhallinen |

## Käyttöohje

### Joka kerta kun tunnet tunteen, tee tämä harjoitus:

```
1. Mitä tunnen nyt? _______
2. Mikä laukaisi tämän? (Todellinen tapahtuma vai kuvitelma?) _______
3. Mitä ennustin tapahtuvan? "Ennustin, että _______ tapahtuu"
4. Toteutuiko ennustukseni?  Toteutui / Epäonnistui / Yllätys / Odotettu
```

Analyysiä ei tarvita. Kaivamista ei tarvita. Pelkkä ylös kirjoittaminen rikkoo jo puolet lumouksesta.

### Kolme tekniikkaa heti käytettäväksi

**Kun olet ahdistunut:** Kirjoita ylös lopputulos, jota pelkäät. Kysy itseltäsi: onko tämä tosiasia vai vain kuvitelmasi?

**Kun olet vihainen:** Ennen kuin reagoit, kysy itseltäsi: mikä odotuksistani ei täyttynyt? Oliko se kohtuullinen?

**Kun viivyttelet:** Laske rimaa "kirjoita vain yksi lause" tai "avaa vain tiedosto". Luo pieni voitto katkaistaksesi negatiivisen kierteen.

|--------|---------|
