# แบบจำลองความคาดหวัง-การตรวจสอบ

> **อารมณ์ = ความคาดหวัง vs ความเป็นจริง**

คุณเคยมีช่วงเวลาแบบนี้ไหม?

> "ฉันรู้ว่าไม่ควรกังวล แต่ก็หยุดไม่ได้"
> "ฉันรู้ว่าควรเริ่มทำ แต่ก็ผัดวันประกันพรุ่งอยู่เรื่อย"
> "เรื่องนั้นเกิดขึ้นนานแล้ว แต่ฉันยังโกรธอยู่"

**อารมณ์ของคุณไม่ได้มาจากเหตุการณ์ภายนอก มันมาจากการทำนายอัตโนมัติในใจคุณที่ชนกับความเป็นจริง**

นี่ไม่ใช่การช่วยเหลือตัวเองแบบผิวเผิน มันเป็นเครื่องมือทางปัญญาที่ใช้ได้จริงในทุกวัน

---

## การวินิจฉัยด่วน

### เมื่อคุณกังวล

```
ใจคุณทำนาย: "ฉันอาจทำพลาด"
การทำนายนี้ทำให้คุณกังวล — ไม่ใช่เพราะมันเกิดขึ้น
แต่เพราะคุณ "เห็น" ผลลัพธ์ที่ไม่ดีในหัวแล้ว
```

### เมื่อคุณโกรธ

```
ความคาดหวังของคุณ: "พวกเขาควรจะยุติธรรม / เชื่อถือได้ / เข้าใจ"
ความเป็นจริงเบี่ยงเบนจากความคาดหวังของคุณ และคุณสูญเสียการควบคุม
ความโกรธไม่ได้เกี่ยวกับสิ่งที่อีกคนทำ — แต่มันเกี่ยวกับความคาดหวังที่ไม่ได้รับการตอบสนองของคุณ
```

### เมื่อคุณผัดวันประกันพรุ่ง

```
คุณอยากทำอะไรให้เสร็จ (ความคาดหวังเชิงบวก)
แต่ทุกขั้นตอนเบี่ยงเบนจากความคาดหวังของคุณ (ช้า, หาไฟล์ไม่เจอ, ติดขัด)
"ความล้มเหลวของความคาดหวัง" เล็ก ๆ ต่อเนื่อง → อารมณ์เชิงลบ → การหลีกเลี่ยง → การผัดวันประกันพรุ่ง
```

## แบบจำลองนี้คืออะไร

ในหนึ่งประโยค: **อารมณ์ = ความแตกต่างระหว่างสิ่งที่คุณคาดหวังกับสิ่งที่เกิดขึ้น**

| แนวคิด | คำอธิบายง่าย ๆ |
|--------|---------------|
| **ความคาดหวัง** | การทำนายอัตโนมัติที่ใจคุณทำเกี่ยวกับสิ่งที่จะเกิดขึ้นต่อไป |
| **ตัวกระตุ้น** | บางสิ่งที่เกิดขึ้นจริง หรือบางสิ่งที่คุณจินตนาการ |
| **อารมณ์** | ปฏิกิริยาของร่างกายหลังจากความคาดหวังของคุณถูก "ตรวจสอบ" |

**ข้อแตกต่างสำคัญ:** สิ่งที่กระตุ้นคุณเป็นเรื่องจริง หรือเป็นเพียงสิ่งที่คุณจินตนาการ?

### 4 สถานการณ์

| คุณคาดหวัง | เกิดขึ้น | คุณรู้สึกอย่างไร |
|------------|---------|----------------|
| ดี 👍 | ดี 👍 | มีความสุข, พอใจ |
| ดี 👍 | ไม่ดี 👎 | โกรธ, ผิดหวัง |
| ไม่ดี 👎 | ดี 👍 | ประหลาดใจ, โล่งอก |
| ไม่ดี 👎 | ไม่ดี 👎 | กลัว, หดหู่ |
| เป็นกลาง | อะไรก็ได้ | สงบ |

## วิธีใช้

### ทุกครั้งที่คุณรู้สึกถึงอารมณ์ ให้ทำแบบฝึกหัดนี้:

```
1. ฉันรู้สึกอะไร? _______
2. อะไรกระตุ้นสิ่งนี้? (จริงหรือจินตนาการ?) _______
3. ฉันทำนายว่าจะเกิดอะไรขึ้น? "ฉันทำนายว่า _______ จะเกิดขึ้น"
4. การทำนายของฉันได้รับการตรวจสอบหรือไม่?  สำเร็จ / ล้มเหลว / ประหลาดใจ / คาดไว้
```

ไม่ต้องวิเคราะห์ ไม่ต้องขุดคุ้ย แค่เขียนลงไปก็ทำลายครึ่งหนึ่งของมนต์สะกดแล้ว

### สามเทคนิคที่ใช้ได้ทันที

**เมื่อกังวล:** เขียนผลลัพธ์ที่คุณกลัว ถามตัวเอง: นี่คือข้อเท็จจริงหรือแค่จินตนาการของคุณ?

**เมื่อโกรธ:** ก่อนที่จะตอบสนอง ถามตัวเอง: ความคาดหวังใดของฉันที่ไม่ได้รับการตอบสนอง? มันสมเหตุสมผลไหม?

**เมื่อผัดวันประกันพรุ่ง:** ลดมาตรฐานลงเป็น "แค่เขียนหนึ่งประโยค" หรือ "แค่เปิดไฟล์" สร้างชัยชนะเล็ก ๆ เพื่อทำลายวงจรเชิงลบ

## เจาะลึก

| แนวคิด | คำอธิบาย |
|--------|---------|
| **ความปรารถนาหลัก** | สิ่งที่คุณต้องการจริง ๆ ภายใต้พื้นผิวของความคาดหวัง |
| **การป้องกันทางจิตวิทยา** | ข้ออ้างและเหตุผลที่คุณใช้เพื่อปกป้องตัวเอง |
| **รอยประทับจากอดีต** | ประสบการณ์ในอดีตหล่อหลอมรูปแบบความคาดหวังปัจจุบันของคุณอย่างไร |
| **การติดตามอารมณ์** | ติดตามทุกอารมณ์กลับไปยังความคาดหวังที่อยู่เบื้องหลัง — ยิ่งฝึกฝนมากเท่าไหร่ คุณยิ่งเฉียบคมมากขึ้นเท่านั้น |
