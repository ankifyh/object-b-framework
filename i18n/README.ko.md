> **감정 = 기대 vs 현실의 차이**

이런 순간이 있지 않나요?

> "불안하면 안 된다는 걸 알지만, 어쩔 수 없어요."
> "해야 하는 건 알지만 계속 미루게 돼요."
> "그 일은 이미 지났는데도 아직 화가 나요."

**당신의 감정은 외부 사건에서 오지 않습니다. 당신 마음속의 자동적인 예측이 현실과 충돌할 때 생겨납니다.**

이것은 자기계발용 이야기가 아닙니다. 매일 사용할 수 있는 실용적인 인지 도구입니다.

---

## 빠른 진단

### 불안할 때

```
당신의 마음이 예측: "내가 망칠지도 몰라"
이 예측이 불안을 만듭니다 — 실제로 일어나서가 아니라,
머릿속에서 나쁜 결과를 이미 '봤기' 때문입니다.
```

### 화날 때

```
당신의 기대: "상대가 공정해야/믿을 수 있어야/이해해야 한다"
현실이 그 기대에서 벗어나면 감정을 통제할 수 없습니다.
화는 상대방의 행동 때문이 아니라 — 충족되지 않은 당신의 기대 때문입니다.
```

### 미룰 때

```
무언가를 끝내고 싶다 (긍정적 기대).
하지만 매 단계마다 기대가 무너진다 (느림, 파일을 못 찾음, 막힘).
작은 '기대 실패'가 쌓인다 → 부정적 감정 → 회피 → 미루기.
```

## 이 모델이란

한 문장으로: **감정 = 예상했던 것과 실제 일어난 것의 차이**

| 개념 | 쉽게 설명 |
|------|----------|
| **기대** | 당신의 마음이 다음에 무슨 일이 일어날지 자동으로 예측하는 것 |
| **트리거** | 실제로 일어난 일, 또는 당신이 상상한 일 |
| **감정** | 기대가 '검증'된 후 당신의 신체 반응 |

**핵심 구분:** 트리거는 현실인가요? 아니면 당신이 상상한 것인가요?

### 4가지 시나리오

| 기대 | 현실 | 감정 |
|------|------|------|
| 좋음 👍 | 좋음 👍 | 행복, 만족 |
| 좋음 👍 | 나쁨 👎 | 분노, 실망 |
| 나쁨 👎 | 좋음 👍 | 놀람, 안도 |
| 나쁨 👎 | 나쁨 👎 | 두려움, 우울 |
| 중립 | 무엇이든 | 평온 |

## 사용 방법

### 감정이 들 때마다 이 연습을 해보세요:

```
1. 지금 느끼는 감정: _______
2. 트리거는? (실제 사건? 상상?) _______
3. 무슨 일이 일어날 거라고 예측했나? "_______이(가) 일어날 거라고 예측했다"
4. 그 예측이 검증되었나?  충족 / 실패 / 놀라움 / 예상됨
```

분석이 필요 없습니다. 파고들 필요도 없습니다. 적어내는 것만으로 절반은 해결됩니다.

### 지금 바로 쓸 수 있는 3가지 기술

**불안할 때:** 두려운 결과를 적어보세요. 사실인가요, 아니면 상상인가요?

**화날 때:** 반응하기 전에 자문하세요: 내 어떤 기대가 충족되지 않았지? 그 기대는 합리적이었나?

**미룰 때:** 기준을 "한 문장만 쓴다" "파일만 연다"로 낮추세요. 작은 성공으로 부정적 루프를 끊습니다.
