> **Emotie = Verwachting vs. Realiteit**

Heb je wel eens van die momenten?

> "Ik weet dat ik niet angstig zou moeten zijn, maar ik kan er niets aan doen."
> "Ik weet dat ik moet beginnen, maar ik blijf het uitstellen."
> "Die gebeurtenis is al lang geleden, maar ik ben nog steeds boos."

**Je emoties komen niet van externe gebeurtenissen. Ze komen van een automatische voorspelling in je geest die botst met de realiteit.**

Dit is geen zweverige zelfhulp. Het is een praktisch cognitief hulpmiddel dat je elke dag kunt gebruiken.

---

## Snelle Diagnose

### Wanneer je angstig bent

```
Je geest voorspelt: "Ik kan dit verprutsen."
Deze voorspelling maakt je angstig — niet omdat het gebeurd is,
maar omdat je het slechte resultaat al in je hoofd hebt "gezien".
```

### Wanneer je boos bent

```
Je verwachting: "Ze zouden eerlijk / betrouwbaar / begripvol moeten zijn."
De realiteit wijkt af van je verwachting en je verliest de controle.
Boosheid gaat niet over wat de ander deed — het gaat over je onvervulde verwachting.
```

### Wanneer je uitstelt

```
Je wilt iets afmaken (positieve verwachting).
Maar elke stap wijkt af van je verwachting (traag, bestanden niet gevonden, schrijversblok).
Constante kleine "verwachtingsfouten" → negatieve emotie → vermijding → uitstelgedrag.
```

---

## Wat is dit model

In één zin: **Emotie = verschil tussen wat je verwachtte en wat er gebeurde.**

| Concept | Simpele Uitleg |
|---------|---------------|
| **Verwachting** | De automatische voorspelling die je geest maakt over wat er gaat gebeuren |
| **Trigger** | Iets reëels dat gebeurt, of iets dat je je voorstelt |
| **Emotie** | De reactie van je lichaam nadat je verwachting is "gevalideerd" |

**Het cruciale onderscheid:** Is de trigger echt of slechts iets dat je je hebt voorgesteld?

### De 4 Scenario's

| Je Verwachte | Er Gebeurde | Hoe Je Je Voelt |
|--------------|-------------|-----------------|
| Goed 👍 | Goed 👍 | Blij, tevreden |
| Goed 👍 | Slecht 👎 | Boos, teleurgesteld |
| Slecht 👎 | Goed 👍 | Verrast, opgelucht |
| Slecht 👎 | Slecht 👎 | Bang, depressief |
| Neutraal | Wat dan ook | Kalm |

## Hoe te Gebruiken

### Elke keer dat je een emotie voelt, doe deze oefening:

```
1. Wat voel ik? _______
2. Wat triggert dit? (Echt of verbeeld?) _______
3. Wat voorspelde ik? "Ik voorspelde dat _______ zou gebeuren"
4. Werd mijn voorspelling gevalideerd?  Vervuld / Mislukt / Verrassing / Verwacht
```

Geen analyse nodig. Geen graven nodig. Alleen al opschrijven verbreekt de helft van de betovering.

### Drie Direct Toepasbare Technieken

**Bij angst:** Schrijf het resultaat op waar je bang voor bent. Vraag jezelf: is dit een feit of slechts je verbeelding?

**Bij boosheid:** Voordat je reageert, vraag jezelf: welke van mijn verwachtingen werd niet vervuld? Was het redelijk?

**Bij uitstelgedrag:** Verlaag de drempel naar "schrijf gewoon één zin" of "open gewoon het bestand". Creëer een kleine overwinning om de negatieve cyclus te doorbreken.

## Verdieping

| Concept | Uitleg |
|---------|--------|
| **Kernverlangens** | Wat je echt wilt onder de oppervlakte van de verwachting |
| **Psychologische Verdediging** | De excuses en redenen die je gebruikt om jezelf te beschermen |
| **Verleden Indrukken** | Hoe ervaringen uit het verleden je huidige verwachtingspatronen hebben gevormd |
| **Emotie Tracing** | Traceer elke emotie terug naar de onderliggende verwachting — hoe meer je oefent, hoe scherper je wordt |
