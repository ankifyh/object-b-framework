# 对象B框架：使用示例

> 实战中的对象B框架应用。

---

## 示例1：工作焦虑

**情境**：明天要做一个重要汇报，今晚睡不着。

```
对象D：焦虑、失眠
对象负B：「我预测我会搞砸这个汇报」
对象C：明天那个汇报（模拟C——尚未发生）
验证模式：对象-+还没发生，但负B在持续的模拟C中自我强化

拆解：
1. 这个焦虑不是来自"汇报本身"，而是来自"我预测汇报会糟糕"这个对象B
2. 对象C（真实汇报）尚未发生，当前所有C都是模拟C
3. 焦虑症抑制想象，本质就是抑制模拟C的恶性循环

应对：
- 找出你能控制的正C：把内容再过一遍、准备一个开场白
- 用对象J反问：我真的100%确信会搞砸吗？过去类似情况的结果如何？
- 调整正B：「我不需要完美，只需要完成」
```

## 示例2：关系冲突

**情境**：朋友约好吃饭但临时放鸽子，非常生气。

```
对象D：愤怒、失望
对象正B：「朋友应该守信」
对象负C：对方临时取消
验证模式：对象+-（正B+负C=愤怒）

愤怒的本质：你的计划（B）没有得到预期的结果（正C）
失控感是愤怒的核心

拆解：
1. 对方的行为触发了你的正B，但正B是你的，不是对方的义务
2. 愤怒背后是恐惧——恐惧被轻视、恐惧关系不稳定
3. 恐惧是欲望的反面：你渴望被重视（对象A），这个欲望的预期（正B）被现实否定了

应对：
- 区分「对方的行为」与「你对ta行为的预期」
- 问自己：我真正需要的是什么？（对象A）
- 考虑处理愤怒后的正C：建立边界、表达感受、或者接受这是对方的局限
```

## 示例3：创作卡壳

**情境**：想写一篇文章，打开文档两小时写不出一个字。

```
对象D：挫败、拖延
对象正B：「我想写出一篇好文章」
微对象负C链：
  - 打开电脑：5秒 vs 预期0.5秒（微负C）
  - 新建文档：发现没标题（微负C）
  - 写第一句：不满意删除（微负C）
  - 想大纲：发现结构模糊（微负C）
  - 分心看手机：自我批评（微负C）
验证模式：持续对象+- → 持续的负D → 拖延逃避

内阻力的根本原因：宏伟的正B遭遇持续微负C链

应对：
1. 降低正B的门槛：「先写50个垃圾词」
2. 把注意力从「要写出好文章」转到「能写下第一行字」
3. 主动创造正C：完成一个小单元就打勾
4. 用计时器（25分钟）制造结构化的正C节奏
```

## 示例4：网上争论

**情境**：看到一条离谱的评论，气得想怼回去。

```
对象D：愤怒、想反驳
对象正B：「观点应该理性、有逻辑」
对象负C：看到了一条不理性、没逻辑的评论
验证模式：对象+-

深度拆解：
网上激烈的骂战不是关于「那个话题」——而是发言者内心小我的投射。

那个让你愤怒的评论，之所以能激怒你，是因为它触碰了你某个固化的正B：
- 「讨论应该基于事实」
- 「蠢人应该闭嘴」
- 「我的观点更正确」

应对：
1. 停止回复，先问：我的哪个预期被触犯了？
2. 看清对方也只是在投射ta的正B——ta的愤怒同样来自失控
3. 用对象H（中性状态）看待：这只是两个B的碰撞，无关真相
```

## 示例5：决策困境

**情境**：在 A 和 B 两个选择之间反复横跳，内耗严重。

```
两个对象B在打架：
对象B1：「选A，A更稳妥」
对象B2：「选B，B更有前景」

这不是事实（C）的问题，而是一个B与另一个B的冲突。
对象C（未来的结果）尚未发生，当前的撕扯全都是模拟C。

拆解：
1. 两个B都只是预测，不是事实
2. 无论选哪个，都会遭遇未选方案的正B的纠缠（「如果当初选了另一个...」）
3. 没有正确的选择，只有选择了之后让选择变得正确

应对：
1. 识别两个B分别是什么
2. 哪个对象A（欲望）更底层？
3. 选一个，然后承诺不再回头看另一个的模拟C
4. 臣服实验：听从自然/良知，而非其中一个小我
```
