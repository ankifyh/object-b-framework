# 预期验证模型：使用示例

> 实战中的应用案例。

---

## 示例1：工作焦虑

**情境**：明天要做一个重要汇报，今晚睡不着。

```
情绪：焦虑、失眠

预期：「我预测我会搞砸这个汇报」

触发事件：明天那个汇报（想象事件——尚未发生）

验证结果：还没发生，但消极预期在持续的想象中自我强化

拆解：
1. 焦虑不是来自"汇报本身"，而是来自"我预测汇报会糟糕"
2. 触发事件（真实汇报）尚未发生——当前所有触发都是想象事件
3. 焦虑的本质是抑制想象，打破想象的恶性循环

应对：
- 找出你能控制的事：把内容再过一遍、准备一个开场白
- 反问自己：我真的100%确信会搞砸吗？过去类似情况的结果如何？
- 调整预期：「我不需要完美，只需要完成」
```

## 示例2：关系冲突

**情境**：朋友约好吃饭但临时放鸽子，非常生气。

```
情绪：愤怒、失望

预期：「朋友应该守信」

触发事件：对方临时取消（真实事件）

验证结果：预期落空（积极预期 + 负面事件 = 愤怒）

愤怒的本质：你的预期没有得到验证
失控感是愤怒的核心

拆解：
1. 对方的行为触发了你的预期，但预期是你的，不是对方的义务
2. 愤怒背后是恐惧——恐惧被轻视、恐惧关系不稳定
3. 恐惧是欲望的反面：你渴望被重视，这个渴望的预期被现实否定了

应对：
- 区分"对方的行为"与"你对ta行为的预期"
- 问自己：我真正需要的是什么？
- 考虑行动方案：建立边界、表达感受、或接受这是对方的局限
```

## 示例3：创作卡壳

**情境**：想写一篇文章，打开文档两小时写不出一个字。

```
情绪：挫败、拖延

预期：「我想写出一篇好文章」

微小触发链：
  - 打开电脑：5秒 vs 预期0.5秒（微小偏差）
  - 新建文档：发现没标题（微小偏差）
  - 写第一句：不满意删除（微小偏差）
  - 想大纲：结构模糊（微小偏差）
  - 分心看手机：自我批评（微小偏差）

验证结果：持续的预期落空 → 持续的负面情绪 → 拖延逃避

拖延的根本原因：宏伟的预期遭遇持续微小的负面验证

应对：
1. 降低预期门槛：「先写50个垃圾词」
2. 把注意力从「要写出好文章」转到「能写下第一行字」
3. 主动创造积极验证：完成一个小单元就打勾
4. 用计时器（25分钟）制造结构化的积极节奏
```

## 示例4：网上争论

**情境**：看到一条离谱的评论，气得想怼回去。

```
情绪：愤怒、想反驳

预期：「观点应该理性、有逻辑」

触发事件：看到了一条不理性、没逻辑的评论（真实事件）

验证结果：预期落空

深度拆解：
网上激烈的骂战不是关于「那个话题」——而是发言者内心预期的投射。

那个让你愤怒的评论，之所以能激怒你，是因为它触碰了你某个固化的预期：
- 「讨论应该基于事实」
- 「蠢人应该闭嘴」
- 「我的观点更正确」

应对：
1. 停止回复，先问：我的哪个预期被触犯了？
2. 看清对方也只是在投射ta的预期——ta的愤怒同样来自失控
3. 用平静状态看待：这只是两个预期的碰撞，无关真相
```

## 示例5：决策困境

**情境**：在 A 和 B 两个选择之间反复横跳，内耗严重。

```
两个预期在打架：
预期A：「选A，A更稳妥」
预期B：「选B，B更有前景」

这不是事实的问题，而是一个预期与另一个预期的冲突。
未来的结果尚未发生——当前的撕扯全都是想象事件。

拆解：
1. 两个预期都只是预测，不是事实
2. 无论选哪个，都会遭遇未选方案的纠缠（「如果当初选了另一个……」
3. 没有正确的选择，只有选择了之后让选择变得正确

应对：
1. 识别两个预期分别是什么
2. 哪个核心欲望更底层？
3. 选一个，然后承诺不再回头看另一个的想象
4. 听从内心深处的良知/自然——而非焦虑的那个声音或反抗的那个声音
```
