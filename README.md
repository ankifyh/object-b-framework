你有没有过这样的时刻：

> 「我知道不该焦虑，但就是控制不住。」
> 「我知道该做事，但就是拖着。」
> 「那件事明明过去了，但我还在气。」

**情绪不像你想的那样来自外界。它来自你内心一个自动的预期，跟现实撞上了。**

这不是鸡汤。这是一个可以每天用的认知工具。

---

## 快速诊断

### 你焦虑的时候

```
你心里在预测：「我可能会搞砸」
这个预测让你焦虑，不是因为事情真的发生了——而是因为你已经提前"看到"了糟糕的结果。
```

### 你愤怒的时候

```
你心里在预期：「ta应该守信 / 公平 / 理解我」
现实偏离了预期，你失控了。
愤怒的本质不是"对方做错了"，是你的预期没有被验证。
```

### 你拖延的时候

```
你想做完一件事（积极预期）
但每打开一步都在偏离预期（打开慢、找不到文件、写不出来）
持续的微小"预期落空" → 负面情绪 → 逃避 → 拖延
```

---

## 这个模型是什么

一句话：**情绪 = 预期 vs 现实的差异。**

| 概念 | 大白话 |
|------|--------|
| **预期** | 你心里自动产生的"接下来会发生什么"的判断 |
| **触发事件** | 真实发生的事，或你脑子里想象的场景 |
| **情绪** | 预期被"验证"之后的身体反应 |

**核心区分：** 触发你情绪的，是真实发生的事，还是你自己想象的事？

### 四种常见情况

| 你预期的 | 实际发生的 | 你的感觉 |
|----------|-----------|---------|
| 好事 👍 | 好事 👍 | 开心、满足 |
| 好事 👍 | 坏事 👎 | 愤怒、失望 |
| 坏事 👎 | 好事 👍 | 惊喜、庆幸 |
| 坏事 👎 | 坏事 👎 | 恐惧、抑郁 |
| 无所谓 | 任何 | 平静 |

## 怎么用

### 每次情绪升起，做这个练习

```
1. 我现在是什么情绪？ ______
2. 触发这个情绪的事是什么？（真实的还是我想象的？）______
3. 我内心预测了什么？「我预测______会发生」
4. 这个预测被验证了吗？ 如愿以偿 / 落空 / 惊喜 / 意料之中
```

不用分析，不用深挖，写下来就已经破了一半。

### 三个立刻能用的技巧

**焦虑时**：把你害怕的那个结果写出来——「我预测____会发生」。看清它之后，问自己：这是事实，还是我想象的？

**愤怒时**：别急着怼。问自己：我的哪个预期没被满足？这个预期合理吗？

**拖延时**：降低门槛到"写一行字""打开文件就行"。主动制造一个小成功，打断负面循环。

## 深入一点

如果你想进一步理解自己，这里还有几个概念：

| 概念 | 解释 |
|------|------|
| **核心欲望** | 你真正想要的是什么（预期背后更深层的动机） |
| **心理防御** | 你用来保护自己的借口和理由 |
| **经验烙印** | 过去的经历如何塑造了你今天的预期模式 |
| **情绪溯源** | 每次情绪升起，反推背后的预期——越练越准 |

## 示例

### 工作汇报前的焦虑

```
情绪：焦虑
触发：明天要汇报（想象事件——还没发生）
预期：「我会搞砸」
验证结果：还没发生，但我在脑海里反复"验证"了100遍

破局：
1. 这个预期是你自己的，不是事实
2. 找到你能控制的极小行动：再过一遍PPT第一页
3. 把「我要完美」换成「我能完成」
```

### 被放鸽子后的愤怒

```
情绪：愤怒
触发：朋友临时取消（真实事件）
预期：「朋友应该守信」
验证结果：预期落空

破局：
1. 你的预期是你的，不是对方的义务
2. 愤怒背后是恐惧——怕被轻视
3. 把注意力从「ta应该」转到「我能」
```

## 谁在用这个模型

- 正在经历情绪困扰的人——看懂自己的情绪从哪来
- 想减少内耗的思考者——识别内心两种预期的冲突
- 写作者/创作者——破解"创作卡壳"的结构性原因
- 只是对人类认知感兴趣的人——一个独特的视角
